## 構成

```
tools/
├── index.html   ← ツール一覧のトップページ
├── README.md    ← このファイル
└── .nojekyll    ← Jekyll処理を飛ばす（消さないこと）
```

## ツールを足すときは

1. ツール本体のHTMLをこのディレクトリに置く
2. `index.html` にカードを1つ足す
3. 下の一覧に行を足す
4. 詳しい使い方・制限は、ツールごとの `〇〇.md` に書く
